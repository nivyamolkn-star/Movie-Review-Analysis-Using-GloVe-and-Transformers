#  Movie Review Analysis Using GloVe + Transformers

##  Project Overview

This project focuses on Natural Language Processing (NLP) techniques to analyse movie reviews using GloVe word embeddings and Transformer models.

It explores word similarity and sentiment analysis to understand the meaning and emotional tone of movie reviews.

##  Objectives

- Understand word embeddings using GloVe.
- Calculate word similarity using Cosine Similarity.
- Perform sentiment analysis using Transformers.
- Classify movie reviews as Positive or Negative.
- Analyse custom movie reviews entered by users.

##  Technologies Used

- Python
- NumPy
- GloVe (Global Vectors for Word Representation)
- Transformers
- PyTorch
- NLP
- Google Colab


##  Implementation

### Part 1: GloVe Word Embeddings

- Download pre-trained GloVe word vectors.
- Load word embeddings into a Python dictionary.
- Retrieve numerical vectors for individual words.
- Calculate cosine similarity between words.
- Compare relationships between words such as:
  - Movie and Film
  - Actor and Actress
  - Story and Book

### Part 2: Transformer-Based Sentiment Analysis

- Install Transformers and PyTorch.
- Create a sentiment analysis pipeline.
- Analyse individual movie reviews.
- Predict positive or negative sentiment.
- Accept custom reviews through user input.
